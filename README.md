## Configuration de la base de données

Avant de lancer le projet :
1. Créer un fichier `.env` à la racine du projet.
2. Ajouter vos propres identifiants PostgreSQL dans le fichier `.env`.
3. Créer une base PostgreSQL nommée `mazepathfinding`.
4. Lancer le projet.

Exemple de `.env` :
DB_USER=user
DB_PASSWORD=your_password_here
